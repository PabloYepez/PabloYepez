# Tienda de Aceites

Esta es una página web de ejemplo para vender aceites de motor. Incluye una lista de productos básica y un carrito de compras en el que se van sumando los artículos seleccionados.

## Cómo usar

Abre `index.html` en tu navegador para ver la página. Puedes agregar productos al carrito y ver el total actualizado en tiempo real.
